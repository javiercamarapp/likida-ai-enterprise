🔐 Authentication

1

Get your API Key

Contact ventas@b2b-ai.local to obtain an API key. Keys are scoped to a tenant for multi-tenant isolation.

2

Include the X-API-Key header

Send your API key in the X-API-Key header with every request to /api/v1/* endpoints.

3

JWT Auth (Enterprise)

For user-level access, use /api/v1/auth/login to get JWT tokens. Send as Authorization: Bearer <token>.

cURL Example
# API Key Authentication curl -H "X-API-Key: YOUR_API_KEY" \ https://api.b2b-ai.local/api/v1/stats # JWT Authentication (after login) curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \ https://api.b2b-ai.local/api/v1/auth/me
