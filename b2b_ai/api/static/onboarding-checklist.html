Prerrequisitos

Documentos y acceso necesarios antes de iniciar la integración.

📄
Documentación Fiscal de la Firma

Verifica que tu firma cuente con la documentación vigente ante el SAT. Estos documentos son obligatorios para cualquier integración.

  • RFC de la firma contable (persona moral o física) Obligatorio Registro Federal de Contribuyentes vigente. Verifica tu estatus en el portal del SAT.
  • E.firma (e.firma digital o e.firma reforzada) Obligatorio Certificado de sello digital (CSD) vigente. Se requiere la contraseña (CIEC) para operaciones de timbrado.
  • RFC y Constancia de Situación Fiscal de cada cliente Obligatorio Al menos un lote inicial de 5–10 clientes para la fase piloto.
  • Cédula de identificación fiscal Recomendado Para validación cruzada de información fiscal de clientes.
🖥
ERP y Sistemas Actuales

Documenta el sistema que utilizas actualmente para contabilidad, facturación y nómina. Likida AI Enterprise se integra con los principales ERPs del mercado.

  • ERP contable actual Obligatorio Ej: CONTPAQi, CONCAR, Aspel, Quipu, QuickBooks, SAP B1, o sistema personalizado. Indicar versión.
  • Sistema de facturación / emisión de CFDI Obligatorio ¿Utilizas PAC propio o de terceros? Indicar proveedor y tipo de timbrado (API, portal, plugin).
  • Sistema de nómina (si aplica) Recomendado Tipo de nómina: propia o de terceros. ¿Manejas CFDI de nómina tipo nómina 1.2 / 1.1?
  • Formato de exportación contable Recomendado CSV, XML, XLSX, o formato nativo del ERP. Necesario para la migración de catálogo de cuentas.
👥
Equipo y Acceso

Identifica a las personas que participarán en la integración y asegúrate de contar con los accesos necesarios.

  • Administrador del proyecto (point of contact) Obligatorio Una persona responsable de coordinar con el equipo de Likida AI Enterprise durante todo el onboarding.
  • Usuario técnico con acceso al ERP Obligatorio Permisos de lectura/escritura para configuración de API y migración de datos.
  • Acceso a internet estable Obligatorio Likida AI Enterprise opera en la nube. Se requiere conexión estable para sincronización en tiempo real.
💡
Consejo: Antes de comenzar, ejecuta un reporte de inventario de facturas de los últimos 3 meses en tu ERP. Esto nos ayudará a dimensionar el volumen de datos y personalizar la integración.

Configuración de Cuenta

Crea tu tenant en Likida AI Enterprise y obtén las credenciales de acceso a la API.

🏢
Creación del Tenant

Tu firma contable operará dentro de un tenant aislado que garantiza la seguridad y separación de datos de cada cliente.

  • Recibir invitación de Likida AI Enterprise Automático Se envía al correo registrado tras firmar el contrato. Verifica bandeja de spam.
  • Completar registro de la firma Obligatorio Nombre comercial, RFC, dirección fiscal, datos del representante legal.
  • Configurar usuarios del equipo Recomendado Asigna roles: Administrador, Contador, Auditor. Mínimo 2 usuarios para la fase piloto.
🔑
API Key y Credenciales de Acceso

Genera y configura las credenciales que usarán tus sistemas para comunicarse con Likida AI Enterprise.

  • Generar API Key (生产环境) Obligatorio Dashboard → Settings → API Keys → Generate New. Guarda la clave de forma segura.
  • Configurar Webhook URL (opcional) Recomendado URL de callback para notificaciones en tiempo real sobre procesamiento de CFDI.
  • Verificar conexión con la API Obligatorio Ejecuta el health check para confirmar que tu cuenta está activa.
# Verificar conexión con Likida AI Enterprise API
curl -X GET https://api.bb-ai.mx/v1/health \
  -H "Authorization: Bearer TU_API_KEY" \
  -H "Content-Type: application/json"

# Respuesta esperada:
{
  "status": "healthy",
  "tenant": "firma-contable-abc",
  "version": "2.1.0"
}
🛡
Seguridad y Permisos

Configura las políticas de seguridad y los niveles de acceso antes de conectar datos reales de clientes.

  • Habilitar autenticación de dos factores (2FA) Obligatorio Política de seguridad: todos los usuarios administradores deben tener 2FA activo.
  • Configurar IP allowlist Recomendado Restringe el acceso a la API desde las IPs de tu oficina (Dashboard → Security → IP Whitelist).
  • Revisar política de retención de datos Obligatorio Likida AI Enterprise retiene datos por 5 años (cumplimiento fiscal MX). Confirma aceptación en el portal.
💡
Consejo: Para la fase piloto, puedes usar la API Key de sandbox (prefijo sb_) que permite pruebas sin impactar datos reales. Solicítala al equipo de soporte.

Pasos de Integración

Conecta tus sistemas con Likida AI Enterprise y configura los módulos de procesamiento.

🏛
Conexión con el SAT

Configura el acceso al Servicio de Administración Tributaria para timbrado, cancelación y consulta de CFDI.

  • Cargar certificado de sello digital (CSD) Obligatorio Sube los archivos .cer y .key del CSD vigente en Dashboard → SAT → Certificados.
  • Configurar contraseña CIEC Obligatorio Se encripta y almacena de forma segura. Nunca se comparte en texto plano.
  • Seleccionar PAC (Proveedor Autorizado de Certificación) Obligatorio Integrado con FacturaDirecta, Finkok, Multifactura, o solicita integración con tu PAC actual.
  • Validar timbrado con CFDI de prueba Obligatorio Envía un CFDI de prueba al sandbox del SAT antes de procesar documentos reales.
📊
Catálogo de Cuentas Contables

Importa y configura tu catálogo de cuentas para que Likida AI Enterprise clasifique automáticamente las transacciones.

  • Exportar catálogo actual del ERP Obligatorio Formatos soportados: CSV, XLSX, XML, JSON. Incluir código, nombre y nivel jerárquico.
  • Subir catálogo a Likida AI Enterprise Obligatorio Dashboard → Contabilidad → Catálogo → Importar. Se valida la estructura automáticamente.
  • Configurar reglas de clasificación automática Recomendado Define mapeos de cuentas para ISR, IVA, nómina y operaciones frecuentes.
  • Validar balance de prueba (trial balance) Obligatorio Importa un balance de prueba del último mes cerrado para verificar el mapeo.
🔔
Configurar Alertas y Notificaciones

Personaliza las alertas automáticas para que tu equipo reaccione ante eventos críticos en tiempo real.

  • Configurar alertas de vencimiento fiscal Obligatorio ISR, IVA, nómina, contabilidad electrónica. Alertas 15, 7 y 1 día antes del vencimiento.
  • Configurar alertas de cobranza Recomendado Facturas vencidas, aging de cartera, clientes con pagos pendientes > 30 días.
  • Configurar alertas de facturación Recomendado Límites de facturación mensual, errores de timbrado, CFDI rechazados por el SAT.
  • Configurar canales de notificación Obligatorio Email, WhatsApp (vía API), SMS, o integración con Slack/Teams.
🏦
Conciliación Bancaria

Conecta tus cuentas bancarias para automatizar la conciliación con movimientos contables.

  • Configurar fuente de movimientos bancarios Obligatorio Upload manual (CSV OFX), API bancaria (BBVA, Banorte, HSBC, Scotiabank), o lectura de email.
  • Mapear cuentas bancarias con catálogo Obligatorio Vincula cada cuenta bancaria con su correspondiente en el catálogo de cuentas contables.
  • Entrenar reglas de conciliación Recomendado Proporciona 3 meses de movimientos conciliados para que el agente de IA aprenda tus patrones.
⚠️
Importante: Nunca compartas tus credenciales CIEC o API keys por correo electrónico o mensajería. Usa el portal seguro de Likida AI Enterprise o solicita una reunión de configuración remota con nuestro equipo.

Primeros 30 Días

Fase piloto, capacitación y puesta en producción con Likida AI Enterprise.

Semana 1 — Días 1–7
Piloto con Datos Sintéticos
Validación completa del sistema con datos de prueba. El objetivo es verificar que cada módulo procesa correctamente antes de conectar datos reales de clientes.
  • Procesar lote de 50 CFDI de prueba (compras, ventas, nómina)
  • Verificar clasificación automática en el catálogo de cuentas
  • Validar conciliación bancaria con movimientos sintéticos
  • Revisar generación de alertas y notificaciones
  • Confirmar que el timbrado funciona con el PAC configurado
Semana 2 — Días 8–14
Capacitación del Equipo
Sesiones de entrenamiento personalizadas para el equipo de tu firma. Cubrimos desde la operación diaria hasta la configuración avanzada.
  • Sesión 1: Panel de control y navegación (2 horas)
  • Sesión 2: Procesamiento de CFDI y contabilidad electrónica (3 horas)
  • Sesión 3: Nómina, cobranza y facturación (2 horas)
  • Sesión 4: Conciliación bancaria y reportes (2 horas)
  • Sesión 5: Administración de usuarios y configuración avanzada (1 hora)
Semana 3 — Días 15–21
Piloto con Datos Reales (3–5 Clientes)
Procesamiento de documentos reales de un subconjunto de clientes. Se ejecuta en paralelo con tu proceso actual para detectar cualquier divergencia.
  • Seleccionar 3–5 clientes representativos de diferentes giros
  • Importar sus CFDI recibidos y emitidos de los últimos 3 meses
  • Ejecutar conciliación bancaria con movimientos reales
  • Comparar resultados de Likida AI Enterprise contra tu proceso manual actual
  • Documentar discrepancias y ajustar configuración
Semana 4 — Días 22–30
Go-Live y Escalamiento
Revisión final, firma del acta de aceptación y migración de la cartera completa de clientes a la plataforma.
  • Revisión de métricas del piloto (precisión, tiempo ahorrado, errores)
  • Firma del acta de aceptación técnica (QA sign-off)
  • Migración de la cartera completa de clientes
  • Activación de todas las alertas y notificaciones en producción
  • Programación de reuniones de seguimiento quincenales (primer mes)
