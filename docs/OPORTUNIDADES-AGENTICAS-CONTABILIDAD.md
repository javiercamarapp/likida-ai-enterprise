# Oportunidades Agenticas en Contabilidad: Análisis Global para Likida (México)

> Investigación realizada: 1 de agosto de 2026
> Fuentes: Sitios web oficiales de cada empresa, structured data, documentación de producto

## RESUMEN EJECUTIVO

El mercado global de contabilidad agéntica está en plena explosión. Existen al menos 15 soluciones maduras en USA/Europa que ya ejecutan tareas contables reales (no solo OCR/clasificación) y están generando revenue significativo. **Ninguna de estas soluciones opera de forma nativa en el mercado fiscal mexicano (SAT, CFDI, nómina mexicana, declaraciones provisionales/definitivas).** Esto representa una ventana de oportunidad de 12-18 meses para Likida.

### Hallazgos clave:
1. **VicAgents™ (Vic.ai)**: Ya tiene agentes autónomos que ejecutan AP end-to-end sobre ERPs — el modelo más avanzado
2. **Truewind**: Convierte bank statements en journal entries listos para GL — directamente adaptable a México
3. **Numeric**: Automatiza el cierre mensual completo con AI — exactamente lo que necesitan los despachos
4. **Docyt**: "Million Dollar Accountant" — AI que hace bookkeeping completo para firms
5. **FloQast**: AI agents para reconciliaciones y close — 3,500+ equipos lo usan
6. **Ramp**: 70,000+ equipos usan sus AI agents para expense management autónomo
7. **En LATAM**: Alegra ya está en México con "Agentes de IA" pero superficiales; Tributi solo hace declaraciones de renta en Colombia

## SECCIÓN 3: PATRONES AGENTIC EMERGENTES

### Patrón 1: "AI Accountant" que hace bookkeeping completo solo
- **Ejemplos**: Zeni AI Accountant Agent, Docyt "Million Dollar Accountant", Truewind Digital Accountant
- **Patrón**: El agente recibe datos fuente (bank statements, invoices, receipts) → genera journal entries → reconcilia → prepara reports → solo escala a humano para excepciones
- **Aplicación México**: Agente que reciba CFDIs + estados de cuenta bancarios → genere pólizas → concilie → genere balanza/estado de resultados

### Patrón 2: Computer use sobre ERPs
- **Hallazgo**: Ninguna de las soluciones investigadas usa "computer use" (screen scraping/RPA sobre ERPs). Todas usan **integraciones API nativas**.
- **Implicación**: El futuro no es RPA sobre CONTPAqi, sino **APIs** o **reemplazar el ERP**.
- **Oportunidad**: Likida podría crear una API layer sobre ERPs mexicanos (CONTPAqi, Aspel) que permita a agentes AI operar sin computer use.

### Patrón 3: Agentes que hacen cierre contable mensual autónomo
- **Ejemplos**: Numeric (90%+ automático), FloQast (3,500+ teams), BlackLine (enterprise)
- **Patrón**: Checklist de cierre → automatización de cada paso → exception handling → approval workflow
- **Aplicación México**: El cierre mensual mexicano incluye: conciliación bancaria, depreciaciones, provisiones, cierre IVA provisional, preparación DIOT. Todo esto es automatizable.

### Patrón 4: Agentes que preparan declaraciones fiscales
- **Ejemplos**: Tributi (declaración de renta Colombia), Alegra Calcula (IVA)
- **Patrón**: Recopilar datos → calcular impuesto → identificar deducciones → generar declaración → presentar
- **Aplicación México**: Declaración IVA provisional (bimestral), ISR provisional (bimestral), ISR definitivo (anual), DIOT (mensual), DIM (mensual). Todas automatizables.

### Patrón 5: Agentes que hacen conciliación bancaria automática
- **Ejemplos**: Numeric (90%+), ReconArt (millions of transactions), Zeni, Truewind
- **Patrón**: Importar extracto bancario → matchear contra registros contables → marcar excepciones → resolver excepciones simples
- **Aplicación México**: Importar CEPs/estados de cuenta de bancos mexicanos → matchear contra CFDIs registrados → marcar excepciones

### Patrón 6: Agentes que procesan AP/AR end-to-end
- **Ejemplos**: Vic.ai (85% no-touch), Stampli (87% automatizado), Tipalti
- **Patrón**: Recibir factura → extraer datos → clasificar → aprobar → registrar → pagar → reconciliar
- **Aplicación México**: Recibir CFDI del SAT → extraer XML → clasificar catálogo cuentas → registrar en ERP → programar pago → conciliar

1. **Motor de reglas fiscales mexicanas** (SAT, CFDI, DIOT, ISR, IVA)
2. **Integración con ERPs mexicanos** (CONTPAqi, Aspel, Contpaq i) — idealmente API, no computer use
3. **Modelo de AI entrenado en contabilidad mexicana** (catálogo de cuentas SAT, NIF)
4. **Equipo de contadores expertos** para validation y edge cases
5. **Infraestructura de compliance** (logs, audit trails, aprobaciones humanas)
